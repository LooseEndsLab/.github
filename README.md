## What is Loose Ends?

Loose Ends is a collection of simple tools for the stuff that’s easy to forget:

* unanswered messages
* follow-ups
* reminders
* recurring life admin
* small digital annoyances

The goal is to reduce mental overhead with tools that are simple, useful, and easy to trust.

## Design principles

* **Do one thing well**
* **Stay lightweight**
* **Reduce mental overhead**
* **Respect personal data**
* **Be useful immediately**
